## Authenticator (pwn category, really reverse + crypto) — 2 solves
Source: p4 team's [`2018-11-8-defcamp-finals/authenticator`](https://github.com/p4-team/ctf/tree/master/2018-11-8-defcamp-finals/authenticator), **read in full**.
A second, independent writeup ([jiancanxuepiao](https://jiancanxuepiao.github.io/2018/11/08/defcamp-finals/)) was only seen as a search excerpt and agrees on AES-128-CTR.
p4's author notes the task was mis-categorised as pwn, which probably explains the low solve count.

**What the service does** (pseudocode recovered from the binary):
1. Wait for the string `HELLO`.
2. Print two random 16-byte values from `/dev/urandom`, call them `bytes1` and `bytes2`.
3. Read your 16-byte answer. If `crypto(bytes2, your_input, key) == bytes1`, print the flag encrypted with the same function.

**Reverse-engineering the crypto.** The binary is C++ and uses boost's SHA-1 (identified by a path string) and Crypto++ for the cipher. Vtable type-info strings
(`CryptoPP::CTR_ModePolicy`, `CryptoPP::Rijndael::Base`) reveal it is **AES-128 in CTR mode**. Breaking on the function showed its arguments: the first is the counter (random per run),
the fourth is the key (constant bytes). To confirm, the author reimplemented it in Python and got the same output as the binary for the same inputs.

**Solving it.** CTR mode is symmetric: encrypting and decrypting are the same XOR with the keystream. To make the check pass, send `AES-CTR(key, ctr=bytes2)` applied to `bytes1`.
Then the encrypted flag the server returns decrypts with the same key and counter.

**Remaining problem — the key.** With ASLR off the key was constant, but with ASLR on **its first byte changed every run** (the other 15 bytes stayed the same; the author checked several Linux systems).
Solution: brute-force the first key byte, 256 values, reconnecting each time and stopping when the decrypted output contains `DCTF`.

**Takeaway.** A task labelled "pwn" can be a pure reversing/crypto problem. Strings and RTTI/vtable names in C++ binaries often identify the library and algorithm in minutes, and a
small unknown (one byte) can simply be brute-forced online.
